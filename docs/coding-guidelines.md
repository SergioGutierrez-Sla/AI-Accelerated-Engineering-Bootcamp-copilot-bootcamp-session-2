# Coding Guidelines

## Purpose

This document defines the coding guidelines that developers should follow across the project. The goal is to keep the codebase consistent, maintainable, readable, and easier to extend over time.

## Core Guidelines

### CG-01: Follow Best Practice Coding Guidelines

- Developers should follow established coding best practices when implementing new features or modifying existing code.
- Code should be written with readability, maintainability, and clarity as primary goals.
- Changes should favor simple, well-structured solutions over unnecessary complexity.

### CG-02: Follow SOLID Principles

- Developers should apply SOLID principles when designing modules, components, and services.
- Code should promote single responsibility, clear abstractions, and extensibility without unnecessary coupling.
- Design decisions should make the code easier to test, maintain, and evolve.

### CG-03: Follow DRY Principles

- Developers should follow the DRY principle and avoid unnecessary duplication.
- Shared logic should be extracted into reusable functions, utilities, components, or services when appropriate.
- Reuse should be balanced with clarity so abstractions remain understandable and useful.

### CG-04: Follow the Airbnb JavaScript Style Guide

- JavaScript and React code should follow the Airbnb JavaScript Style Guide.
- Code formatting, structure, naming, and organization should remain consistent with the Airbnb conventions unless the project explicitly defines an exception.
- New code should align with existing linting and formatting rules derived from that guide.

### CG-05: Use camelCase for Variables and Methods

- Variable names should use camelCase.
- Method names should use camelCase.
- Names should be descriptive and reflect the responsibility of the value or behavior they represent.

## Expected Outcomes

The coding guidelines should be considered applied correctly when:

- code follows widely accepted best practices,
- SOLID and DRY principles are reflected in implementation decisions,
- JavaScript and React code aligns with the Airbnb style guide, and
- variable and method names consistently use camelCase.
